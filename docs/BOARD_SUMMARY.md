# 多卡片汇总 · 2026-10-31

范围：所有项目研究档案的工作版。继承本地原型约定，本轮无 API、无远程请求，不读取或配置密钥。

## 用户流程

1. **连接／选择：通过。** 右击相连的卡片或点卡片右上角的省略号，选择“汇总相连的 N 张卡片”；也可以 Shift 多选后使用“生成汇总卡”。点击已有关系连线也能打开汇总入口。
2. **指定范围：通过。** 弹窗显示来源名称和实际可用内容，允许取消部分来源，至少保留两项。用户可填写标题、关注的问题。
3. **生成结果：通过。** 根据实际正文、笔记、研究卡片、已有标签及已确认的关系理由整理本地摘录，按关注词排序选段。输出一张独立汇总卡及来源连线，连线标为“汇总来源”。仅有目录时不生成全文分析；图片／视频仅使用已有文字描述，不声称识别画面。
4. **编辑与回溯：通过。** 汇总可继续编辑，来源保留对象 ID、正文版本或笔记修订、摘录和锚点 ID；可以定位来源卡片或打开资料／笔记。正文版本或笔记修订变化时显示来源更新提示。
5. **保存与撤销：通过。** 汇总卡、项目引用和来源连线一次提交，可整体撤销／重做。失败保留弹窗内容，不留下半个输出。已归档项目禁用生成操作。刷新后保留汇总及来源。

## 实现边界

- 当前是本地抽取与整理，不是语言模型综合分析；界面明确显示“本地内容整理 · 未连接 AI 模型”。
- 参考 ComfyUI 的节点菜单和节点输入／输出思想，没有复制模型执行引擎。
- 依据：[ComfyUI 官方节点文档](https://github.com/Comfy-Org/docs/blob/main/basic-concepts/nodes.mdx)。
- 汇总来源连接单独标记，不作为“支持／反驳”的研究证据；查找相连材料时排除汇总来源边，避免把历次生成结果反复纳入。
- 不自动覆盖原始材料，不会因为连线而自动向任何模型发送内容。

## 验证

- `npm run build:pages` 通过。
- `npm test`：53/53，通过 6 项新增汇总测试：连通范围与循环、来源版本／可读范围、权限和去重、实际内容生成、结果与来源连接、归档与单项拒绝。
- CUA 实测：右键打开菜单；两卡片汇总；三卡片汇总；编辑并刷新恢复；来源定位；点击“比较”连线打开汇总。
- 三来源汇总前 1 张汇总卡／3 条连线，生成后 2 张／6 条，撤销恢复为 1 张／3 条，重做恢复为 2 张／6 条。
- 保存失败场景：保留标题“待重试的材料汇总”，无新汇总卡、无残留来源连线。
- 运行期间浏览器没有错误日志。测试写入只在隔离评审场景中进行。
- 未接入真实模型，因此没有模型质量、远程响应或费用验证；未声称完成全部无障碍检查。
