## 第十六轮：图片区域笔记的操作流程重做

以当前图片阅读页为范围检查了进入、选择区域、写笔记、保存与回看。旧界面要求用户理解归一化坐标，选区反馈只有数字，默认图片超出阅读区域，保存后缺少当前图片的笔记列表。沿用现有黑白视觉与原有合成示意图，聚焦修复交互，不生成或冒充真实史料图片。参考 [Acrobat 图形批注](https://helpx.adobe.com/acrobat/desktop/share-and-review-documents/review-documents/add-shapes-drawings.html)将图上区域与文字笔记对应，参考 [Zotero 笔记回到原文](https://www.zotero.org/support/pdf_reader)补齐来源回看。

1. 进入：图片默认适合窗口，支持放大、缩小与恢复适合窗口。工具条只保留框选、整图笔记与缩放；删除坐标输入、原始尺寸、版本号、技术定位页脚及图片笔记中的模拟 AI/内容性质分类。
2. 选择：鼠标拖动或依次点击两个对角可框选；可移动选框、拖四角调整大小。提供键盘添加选框、方向键移动、Shift 加方向键调整大小和 Esc 取消；取消保留此前选区与文字草稿。右侧预览精确裁剪所选区域，空白边缘不会显示选区外内容。
3. 记录与保存：右侧只要求笔记内容，标题选填。保存到个人笔记，从项目进入时同时引用到该项目；原图不改写。来源仍保留原资料 ID、版本与归一化区域，兼容既有锚点。失败保留草稿和区域，提供未保存笔记备份；刷新可恢复草稿及调整后的精确区域。
4. 回看与管理：当前图片的笔记列表显示编号，图上对应区域同步标记；同一区域被多条笔记引用时合并编号。点列表或图上编号可定位区域并查看内容，放大状态也会滚到目标区域。查看已有笔记不会覆盖尚未保存的草稿；可继续草稿，或进入既有笔记详情编辑。列表仅包含当前用户及当前图片版本的最新笔记修订。

图片组件同时用于独立阅读、项目内深读及文献对照；对照中工具名为“框选对照区域 / 选择整图”。私人上传图片使用其本地文件，文件缺失时明确提示，不展示伪造原图。保留演示图片标签与原有合成内容。
