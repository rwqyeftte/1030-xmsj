# 文献研究中心

在中文研究准备原型中，你可以检索设计史资料，精读文字、图像和视频，把选段和观察整理到项目画布。[进入网站](https://rwqyeftte.github.io/1030-xmsj/) · [直接检索](https://rwqyeftte.github.io/1030-xmsj/#/search)

## 从精读到项目画布

2026 年 11 月 13 日更新。以《老字号包装的叙事性设计研究》为例，打开文本精读，在「本篇结构」中选择「2.1 叙事主题」即可跳到对应段落。目录沿用原文编号，范围限于本站收录的节选。[打开文章](https://rwqyeftte.github.io/1030-xmsj/#/resources/A02/read?view=text)

1. 选中文本或 PDF 段落、框选图片区域，或标记视频中的时间点与片段。可以为这条材料写下观察，也可以先保留原始来源。
2. 点「放到项目画布」。从项目内进入精读时沿用当前项目，独立阅读时可以选择或新建项目。放置后可继续阅读，也可点「查看画布卡片」。
3. 单击画布卡片查看原始来源和个人观察，点「回到原文」重定位选段、区域或时间。读完可用「返回原工作版位置」继续整理同一张卡片。按住 Shift 单击可多选分组，多张关联卡片可生成可编辑的本地汇总。

## 资料与数据

课程材料包括 4 篇论文节选、4 份书籍节选（共 8 个 PDF）、18 张图片预览和 3 段视频预览。课程包未附这些 PDF 和视频的公开再分发许可，图片预览的原作权利信息未载明。保温瓶专题的 3 张图像另有逐件来源及权利说明，并配有本站原创导读。目录还含明确标记的合成演示记录。

项目、笔记和个人上传文件保存在访客的浏览器中。登录与权限采用本地演示逻辑，问答记录保存在当前标签页的会话中。

## DeepSeek 检索与问答

GitHub Pages 托管静态前端。常规检索、精读、笔记和画布可在前端使用。「AI 辅助检索」、专题与阅读问答、PDF 选段解读通过 Sites 上的 HTTPS 接口调用模型。全站共用 10 个并发名额，每小时请求次数不限。10 个名额都被占用时，等其中一个请求结束即可重试。

辅助检索使用 `deepseek-flash` 提取检索条件。连续问答使用当前提问、最近三轮对话及该阅读范围内的材料。请求 PDF 解读时，所选或录入的文字会随问题提交。[后端配置及发布步骤](docs/GITHUB_PAGES.md)

## 本地运行

使用 Node.js 22，在仓库根目录运行以下命令。

```sh
npm ci
npm run dev
```

本地使用 AI 时，在服务端环境变量或 Git 忽略的 `.env.local` 中设置 `DEEPSEEK_API_KEY`。本地开发服务器通过 `/api/reader` 接收请求。

- `npm test` 运行领域、检索、路由、阅读笔记与画布等测试。
- `npm run build` 构建本地路径模式。 `npm run build:pages` 将 Pages 版本输出到 `dist-pages/`。
- 构建 Pages 后运行 `npm run test:browser`，用本机 Chrome 检查交互。
- `node tests/reader-ai.mjs` 验证 AI 检索流程，附加 `--live` 会发送真实模型请求。

推送到 `main` 会触发测试、构建和发布。具体提交的发布状态见 [GitHub Actions](https://github.com/rwqyeftte/1030-xmsj/actions/workflows/deploy-pages.yml)。
